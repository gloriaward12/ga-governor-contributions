# Georgia Governor 2026 — Contribution Explorer

A static web app for exploring every campaign contribution filed by the committees running for Governor of Georgia in 2026, built from the Georgia Government Transparency & Campaign Finance Commission's public PeachFile data.

* **Overview** — gross/net raised, itemized vs. small-dollar split, named donors, average/median gift, Georgia share, monthly receipts, cumulative curve, gift-size bands.
* **Top donors** — de-duplicated donor leaderboard (name + ZIP) with primary/general/runoff splits, "at limit" flag, repeat-donor and concentration metrics, click-through to every transaction.
* **Contributions** — full sortable ledger with a *Copy filtered CSV* button for Excel / Sheets.
* **Geography** — states, cities, ZIP codes.
* **Employers & occupations** — from the live PeachFile record of each itemized gift (the bulk export omits these fields).
* **Reports, returns & loans** — receipts by filing period, refunds, candidate loans.
* **Compare the field** — every registered committee side by side.

Global filters (search, dates, election, kind, contributor type, state, amount, report) apply to every tab.

## Deploy

The site is 100% static: `public/` is the web root. On Vercel, import the repo and set the **Output Directory** to `public` (no build command). It also works on Netlify, GitHub Pages, S3 or any static host.

## Refreshing the data

Requires Node 18+ and Python 3 with `pandas`.

```bash
npm run refresh     # 1) download bulk files  2) pull occupation/employer from the API  3) rebuild public/data/*.json
```

Then commit `public/data` (Vercel redeploys automatically). The bulk files are regenerated by the Commission nightly at ~2 AM ET; the enrichment step also picks up Two-Business-Day reports filed after that extract.

To add or remove committees, edit `IDS` in `scripts/fetch_bulk.mjs`, `FILERS` in `scripts/enrich.mjs` and `CANDS` in `scripts/build_data.py` (entity IDs come from PeachFile's candidate registry: office *Governor*, *2026 Georgia State Election*).

## Data notes

* Unitemized contributions carry no donor identity in Georgia filings, so donor counts, geography and employer views cover itemized gifts only.
* Donor de-duplication is by normalized name + 5-digit ZIP and can split a donor who used two addresses.
* "Not Employed" is the default many online donation platforms record when a donor skips the field.
* Loans are listed twice in the Commission's export; the app collapses duplicates. Interest-earned rows are excluded from contribution totals.
* Totals reconcile to the Commission's candidate registry ("Total Contributions") for every committee as of the extract date.

Source: https://peachfile.ethics.ga.gov (public campaign finance data).
