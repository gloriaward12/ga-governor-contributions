      What a payment-accuracy program looks like

      A monthly error-rate estimate from the state's own quality-control sample, months before FNS publishes the annual number. Case-level error attribution by county, office, worker tenure and error type, so supervisors see where the rate is made. Decision support inside the eligibility workflow for the two error types that dominate Georgia's rate. A public page like this one, updated as the numbers move, so the Governor, the General Assembly and FNS see the same trend at the same time.

      Georgia enacted $6.88 million for a SNAP payment-accuracy innovation effort in FY2027 (the Governor had proposed $12 million) and $6.2 million for Gateway changes.
